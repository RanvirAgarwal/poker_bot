# Maintain Project Memory Skill

## Purpose
Maintains persistent project memory across conversations, resets, and compactions in `MEMORY.md`.

## Triggers
- After every completed milestone or benchmark run
- After architecture or schema changes
- Before handing off or ending a work session

## Structure
`MEMORY.md` must contain all 9 required sections:
1. Objective and verified constraints
2. Current status (implemented & tested vs planned vs blocked)
3. Architecture map
4. Decisions log (with IDs)
5. Skills catalog
6. Experiments and findings (with measured numbers and CIs)
7. Best working candidate
8. Active work
9. Resume instructions (exact verified commands)
